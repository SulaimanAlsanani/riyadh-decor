الدهانات الداخلية والخارجية

تجديد الجدران والأسقف والواجهات بألوان تُختبر في إضاءة المكان، وتجهيز يناسب حالة كل سطح.

تفاصيل الخدمة: الدهانات

ديكورات الشاشات

خلفيات تلفزيون تجمع بين الكسوة والإضاءة والتخزين، بتوزيع يحسب مكان الشاشة والمقابس قبل التركيب.

تفاصيل الخدمة: ديكورات الشاشات

الجبس بورد والأسقف

تخطيط أسقف وجدران وقواطع الجبس بما يلائم الارتفاع المتاح ومسارات التكييف والإنارة.

تفاصيل الخدمة: جبس بورد

بديل الخشب والفواصل

كسوات وفواصل بشرائح وخطوط نظيفة، مع اختيار يراعي الخصوصية وحركة المرور داخل المساحة.

تفاصيل الخدمة: بديل الخشب والفواصل

بديل الرخام

كسوات جدارية بملمس حجري وتوزيع متوازن للعروق، مع عناية بالفواصل والنهايات حول الزوايا والمقابس.

تفاصيل الخدمة: بديل الرخام

براويز الفوم والنعلات

براويز جدارية ونعلات تتناسب مع ارتفاع الغرفة وتوزيع الأثاث والأبواب.

تفاصيل الخدمة: فوم ونعلات

ورق الجدران

اختيار وتركيب أكسية جدارية تناسب الإضاءة وعرض الجدار مع تخطيط تكرار النقشة.

تفاصيل الخدمة: ورق الجدران

أرضيات الباركيه

أرضيات خشبية المظهر مع اختيار شكل الرص ومعالجة الانتقالات بين الغرف والأبواب.

تفاصيل الخدمة: أرضيات باركيه

عزل الصوت والتنجيد

دراسة مواضع انتقال الصوت أو الصدى لاختيار معالجة مناسبة للجدران والأبواب والأسقف.

تفاصيل الخدمة: عزل صوت وتنجيد

الرخام والبلاط

تنسيق البلاط والرخام للأرضيات والجدران مع تخطيط اتجاه الرص ومواقع القطع والفواصل.

تفاصيل الخدمة: رخام وبلاط

خلفيات الأسرة

جدار ومساند وإضاءة خلف السرير بتوزيع ينطلق من عرض السرير ومسار الوصول للمقابس.

تفاصيل الخدمة: خلفيات الأسرة
